> **版本口径**：本文调研截止于 **2026-07-25**，以当前正式版 **Minecraft Java Edition 26.2（Chaos Cubed）** 为基准。26.3 快照、基岩版特性、模组、数据包和服务器插件不计入默认结论。

“生电机器”并不是游戏内的正式分类。本文把它定义为：借助方块更新、随机刻、生物生成与 AI、战利品表、村庄、结构、维度和红石物流，重复生产资源或支撑生产线运行的装置。

本文追求的是**生产机制层面的完整**，不是穷举互联网上每一种外形、效率档位和作者设计。相同底层机制的单维、双维、堆叠、下压式、传送门式设计会合并为一个“机器族”。

## 结论先行

1. Java 26.2 中，大多数基础建材、食物、药水原料、红石元件和常用消耗品都能形成可再生生产链。
2. “可再生”“能自动生成”“能全自动入库”是三件不同的事。冰、黑曜石和主流牛奶来源虽然可重复取得，但仍有精准采集、玩家挖掘或右键交互瓶颈。
3. 自 1.21.5 起，实体处理区块即使没有附近玩家也能收到随机刻；但自然刷怪仍要求玩家在有效距离内。
4. 自 1.21.9 起，Java 已移除传统出生区块。旧攻略中“建在出生区块就永久运行”的结论在 26.2 不成立。
5. TNT 复制、重力方块复制、基岩破坏等是漏洞设施，不应与正常可再生机制混在同一张产物表中。
6. 试炼刷怪笼及试炼钥匙可重复刷取，但固定玩家通常只能开启每个宝库一次，所以沉重核心等限领物不是普通单人生存中的无限资源。宝库仅记录 128 个 UUID 的多人边界另行说明。

## 调研口径与图例

### 自动化等级

| 标记 | 含义 | 典型例子 |
| --- | --- | --- |
| **全自动** | 输入供应、生产、收割和收集均可持续完成，不需要玩家重复操作 | 铁场、甘蔗场、鸡蛋场 |
| **挂机自动** | 机器自行运行，但自然刷怪、刷怪笼或玩家状态要求玩家留在特定位置 | 苦力怕塔、末影人塔、烈焰人刷怪笼 |
| **半自动** | 红石完成主要流程，玩家仍要播种、喂食、击杀、装桶或触发 | 树场、牛场、熔岩炼药锅 |
| **手动设施** | 装置只改善效率，核心交互仍由玩家完成 | 交易所、钓鱼机、龙息收集站 |
| **基础设施** | 本身不净产资源，只负责加载、加工、运输、分类或清场 | 区块加载器、仓储、世界吞噬者 |

### 附加限制

| 标记 | 含义 |
| --- | --- |
| **玩家击杀** | 某些稀有掉落或经验要求玩家或驯服狼完成击杀 |
| **结构限定** | 必须利用海底神殿、下界要塞、试炼密室、紫水晶母岩等固定目标 |
| **群系限定** | 生成或生长依赖特定群系、温度、天气或高度 |
| **耗材型** | 机器可以自动，但持续消耗骨粉、玻璃瓶、剪刀、TNT 等输入 |
| **漏洞型** | 利用非预期行为，可能被更新或服务端软件修复 |

“全自动”只表示**玩家不必持续操作**，不表示世界关闭后仍会运行，也不自动满足区块加载、随机刻、怪物上限和玩家距离条件。

## 运行机器前必须知道的规则

| 规则 | Java 26.2 中的影响 |
| --- | --- |
| 区块加载 | 红石、熔炉、生物 AI 和随机刻都要求相应区块处于正确加载等级；卸载区块会冻结机器。 |
| 出生区块 | [1.21.9 已移除出生区块](https://minecraft.wiki/w/Spawn_chunk)。无人值守设施需玩家、传送门加载器、末影珍珠加载器或 `/forceload`。 |
| 随机刻 | [1.21.5 起](https://minecraft.wiki/w/Java_Edition_1.21.5)，实体处理区块无需附近玩家也可随机刻，适用于作物、滴水石、紫水晶、炼药锅等。 |
| 自然刷怪 | 普通敌对生物的有效生成点通常要距玩家 24 至 128 格；超过 32 格后可随机消失，超过 128 格会立即消失。区块加载器不能代替挂机玩家。 |
| 刷怪笼 | 普通刷怪笼通常要求玩家位于 16 格内；试炼刷怪笼使用自己的激活和冷却规则。 |
| 怪物上限 | 同一维度中同时运行的自然刷怪农场会竞争怪物上限。26.2 的硫方怪也占用敌对上限；刷怪笼、试炼刷怪笼和传送门生成不属于普通自然生成。 |
| 玩家击杀判定 | 经验、烈焰棒、部分装备、稀有箭、兔子直接掉落的兔子脚、幻翼膜、凋灵骷髅头颅等不能一概用环境击杀取得。 |
| `mob_griefing` | 关闭后会破坏村民种田、狐狸采浆果和自动猪灵以物易物等生产线；26.2 的游戏规则名称已采用命名空间和 snake_case。 |
| 服务端差异 | Paper、Purpur、Spigot、Fabric 模组和服主配置可能修改传送门、实体挤压、漏斗、村民恐慌、TNT 复制及生成范围。 |
| 卸载安全 | 飞行器、世界吞噬者、方块流和高速爆破室在运行中跨越未加载区块，可能错位或自毁。 |

### 树场与下界巨型菌

Java 没有能放置任意方块的通用设备，发射器也不能种普通树苗。因此大多数传统树场属于“玩家持续放树苗，机器催生、推木和爆破”的挂机式半自动机器。

| 树场族 | 产物 | 自动化与适配性 |
| --- | --- | --- |
| 橡树 | 橡木、树苗、木棍、苹果，花附近可生成蜂巢 | 大型分枝树会增加限形与叶处理难度。 |
| 白桦 | 白桦木、树苗、木棍、蜂巢 | 树形规整，是通用活塞树场中较容易适配的树种。 |
| 云杉 | 云杉木、树苗；巨型云杉还能生成灰化土 | 兼有 1×1 与 2×2 树型，巨型树要求大净空。 |
| 丛林树 | 丛林木、树苗、藤蔓，可承载可可果 | 2×2 树型复杂且树苗掉率低，自持设计更难。 |
| 金合欢 | 金合欢木、树苗 | 斜干和分叉方向不稳定，通常需要专用限形。 |
| 深色橡树 | 深色橡木、树苗、木棍、苹果 | 必须 2×2，树苗回收接近盈亏线。 |
| 樱花树 | 樱花木、树苗、树叶、蜂巢 | 分枝不规则；玩家种树不会顺带生成地面的粉红色花簇。 |
| 红树 | 红树木、根、沾泥的红树根、胎生苗、蜂巢 | 根系和树冠极不规则，是完整机械化最困难的主世界树种之一。 |
| 苍白橡树 | 苍白橡木、树苗、木棍、树叶 | 必须 2×2；玩家种出的树不会生成嘎枝之心、树脂或苍白垂须。 |

| 巨型绯红菌场 | 绯红菌柄、下界疣块、菌光体、垂泪藤 | 小型菌和巨型菌都能用骨粉流程生成，复杂设计可全自动，并用疣块堆肥回收骨粉。 |
| 巨型诡异菌场 | 诡异菌柄、诡异疣块、菌光体 | 同上；不产垂泪藤。菌柄不能烧成木炭。 |
| 蜂巢生成树场 | 蜂巢、蜜蜂、对应木材 | 花附近生长橡树、白桦或樱花树有概率带蜂巢；蜂巢块本身要用精准采集取得。 |

树场常见后端有三种：玩家持斧挖掘、消耗 TNT 的爆破室、TNT 复制爆破室。第三种应明确标为漏洞型。

### 药水效果衍生农场

1. **渗浆（Oozing）**：带效果生物死亡后产生史莱姆，可把廉价生物转成黏液球来源，但受局部实体挤压限制。
2. **寄生（Infested）**：生物受伤时有概率生成蠹虫，适合经验或实体机制设施，不产生独特物品。
3. **盘丝（Weaving）**：带效果生物死亡后可生成蜘蛛网，使蜘蛛网成为正常可再生方块；部分场景要求 `mob_griefing=true`。
4. **蓄风（Wind Charged）**：死亡时产生风爆，主要用于击退、运输和装置触发，不直接净产独特资源。

### 流浪商人补齐的低吞吐资源

流浪商人不是稳定工业机器，但其无限刷新使一些原本有限或难复制的物品成为理论可再生资源，重点包括：

- 沙、红沙、浮冰、蓝冰、灰化土；
- 五色珊瑚块、小型垂滴叶、睡莲、海泡菜；
- 多种树苗、种子、花、藤蔓、苔藓、苍白植物；
- 火药、命名牌、黏液球、鹦鹉螺壳；
- 硫黄尖锥等 26.2 资源种源。

它们适合“补种源”和收藏，不适合代替大规模沙场或建材工业。

流浪商人生成平台与捕获仓还能集中商人、行商羊驼和拴绳。交易仍需玩家操作；击杀正在持有或饮用对应消耗品的商人，有基础 8.5% 概率掉落奶桶或隐身药水，因此“牛奶只能靠挤奶取得”存在极低吞吐例外。

### 硫黄与朱砂的 26.2 边界

- 硫黄尖锥是可再生方块，可继续合成硫黄、磨制、砖制和雕纹系列以及烈性硫黄。
- 烈性硫黄可配合岩浆块或熔岩制造周期性或持续喷发的间歇泉，是实体运输和机关基础设施，不会凭空产物品。
- 硫方怪死亡不会掉硫黄。
- 朱砂（Cinnabar）及其建筑系列来自有限地形开采，不属于正常无限生产线。

| 海带燃料线 | 海带、其他启动燃料 | 干海带、干海带块 | 可回烧形成燃料闭环，并积累熔炉经验。 |
| 竹子燃料线 | 竹子 | 熔炉燃料 | 全自动但单根燃烧时间短，需要高吞吐物流。 |
| 木炭线 | 主世界原木 | 木炭、经验 | 全自动加工；下界菌柄不能烧成木炭。 |
| 滴水石熔岩燃料线 | 熔岩炼药锅、桶 | 每桶可供大量熔炼 | 装桶是玩家瓶颈，适合批量补充超级熔炉。 |

## 加工机器

### 熔炉、烟熏炉与高炉

| 机器 | 主要输出 | 处理速度 | 备注 |
| --- | --- | --- | --- |
| 普通熔炉阵列 | 石头、平滑石、玻璃、红砖、陶瓦、绿色染料、木炭、平滑玄武岩、熟食等 | 10 秒/件/炉 | 顶部进原料、侧面进燃料、底部出成品；适用配方最广。 |
| 烟熏炉阵列 | 熟肉、熟鱼、烤马铃薯、干海带 | 5 秒/件/炉 | 只处理食物，吞吐与耗燃料速度都是普通熔炉两倍。 |
| 高炉阵列 | 金属矿物、远古残骸、可回收金属装备 | 5 秒/件/炉 | 不处理石头、沙、黏土和食物。 |
| 超级熔炉 | 上述任意大批量产品 | 取决于并联炉数与物流 | 漏斗矿车均分输入，底部漏斗汇总；区块卸载后暂停。 |
| 熔炉经验银行 | 经验 | 随熔炼积累 | 漏斗取走成品不会清空炉内累计经验，最终仍需玩家手取成品或破坏炉子。 |

### 自动炼药机

自动炼药机负责流程编排，不会让原料凭空再生。

- 顶部漏斗加入药材，侧面加入瓶和烈焰粉。
- 底部漏斗必须在中间步骤锁住，否则会提前抽走半成品。
- 一次炼制可处理三瓶，药水不可堆叠，仓储通常比炼制速度更早成为瓶颈。
- 可自动酿造的药水类型包括夜视、隐身、跳跃、抗火、迅捷、迟缓、水肺、治疗、伤害、剧毒、再生、力量、虚弱、缓降、神龟，以及虫蚀、渗浆、盘丝和蓄风。
- 火药、龙息可继续加工为喷溅、滞留药水和药箭。

### 合成器生产线

[合成器](https://minecraft.wiki/w/Crafter)自 Java 1.21 起让大量“农场成品压缩”真正全自动化。常见产品线包括：

- 铁、金、铜的粒、锭、块互转；
- 骨头转骨粉，西瓜片还原西瓜；
- 竹块、干海带块、蜂蜜块、蜜脾块；
- 雪球转雪块，冰转浮冰再转蓝冰；
- 紫水晶碎片、滴水石锥、黏土球和红砖压块；
- 纸、书、烟花火箭、TNT、金苹果、金胡萝卜；
- 漏斗、活塞、发射器、铁轨等批量元件。

合成器不能替代切石机、铁砧、砂轮、锻造台、附魔台、织布机和制图台的玩家 GUI 操作。

这些装置通常不净产资源，但决定大型生电基地是否能稳定运行。

### 分类与运输机器

| 机器 | 处理对象或结果 | 核心边界 |
| --- | --- | --- |
| 单物品漏斗分类器 | 将可堆叠物按类型分箱 | 普通漏斗吞吐为 2.5 件/秒；模板必须与目标物可堆叠，16 堆叠物需不同配比。 |
| 多物品分类器 | 多种物品共享箱列 | 密度高，但时序、模板保持、回流和溢出保护更复杂。 |
| 不可堆叠物分离器 | 工具、装备、药水、潜影盒等 | 利用比较器信号强度先粗分，不会自动识别每种附魔和耐久。 |
| 铜傀儡分类区 | 从铜箱子取物并尝试送入普通/陷阱箱 | 每次最多取 16 个；Java 会忽略耐久、附魔、名称、药水内容等差异，不能代替精确的物品组件分类。 |
| 潜影盒装载机 | 散件变成满潜影盒 | 发射器放盒，漏斗装填，比较器检测，活塞打掉后收集。 |
| 潜影盒卸载机 | 满盒拆成散件并回收空盒 | 发射器放盒，底部漏斗抽空，比较器检测后活塞打掉。 |
| 水道/冰道 | 大批量掉落物运输 | 吞吐高、实体可合堆；下界不可用水，掉落物在已加载区块中约 5 分钟后消失。 |
| 漏斗管 | 方向确定的短距离物流 | 简单但铁耗和服务器开销较高；大规模使用要控制常开漏斗数量。 |
| 漏斗矿车 | 高速拾取、炉组均分、隔方块收获 | Java 从上方容器抽取很快，但最终卸货仍受下方漏斗速度影响。 |
| 投掷器管/电梯 | 水平或向上输送物品 | 需要时钟；Java 投掷器受准连接影响。 |
| 铁路批运 | 箱子矿车和漏斗矿车远距离运输 | 需要完整加载线路、可靠装卸站和空车返回逻辑。 |
| 传送门物流 | 跨维度运输和下界 8:1 距离压缩 | 要精确设计门链接、接收端和区块票；掉落物仍会超时。 |
| 自动垃圾处理 | 销毁溢出物 | 岩浆、仙人掌、火或虚空都不可恢复，必须放在溢出保护之后。 |

### 附魔可再生边界

- 灵魂疾行可由猪灵以物易物无限取得。
- 大多数普通和宝藏附魔可通过附魔台、图书管理员或钓鱼重复取得。
- 迅捷潜行仍依赖远古城市有限战利品。
- 风爆依赖不祥宝库；固定玩家的固定宝库不可重复开启，因此不属于普通单人生存中的无限附魔。128 个 UUID 的多人记录边界不改变这一实用分类。

## 正常机制下不能无限刷什么

“世界无限大，所以总能继续探索”不等于同一资源点能再生，也不等于存在生电农场。

| 类别 | 典型不可再生物 | 原因 |
| --- | --- | --- |
| 原始矿物 | 钻石、远古残骸、下界合金原料、各类矿石块和原矿 | 只能继续开采有限地形，没有正常净生成机制 |
| 末地有限物 | 龙蛋、龙首、鞘翅 | 龙蛋只在首次击杀生成，龙首和鞘翅来自有限结构 |
| 海洋结构物 | 海洋之心、海绵、湿海绵 | 结构或远古守卫者数量有限；湿海绵只是可反复烘干使用 |
| 远古城市战利品 | 回响碎片、唱片残片 5、唱片 5、迅捷潜行 | 仅来自结构战利品 |
| 宝库限领物 | 沉重核心、部分唱片/模板、风爆 | 固定玩家对同一宝库通常只能开一次 |
| 结构稀有战利品 | 附魔金苹果、唱片 `Bounce` 等 | `Bounce` 仅来自硫黄洞穴废弃矿井的运输矿车；这类战利品没有正常再生机制 |
| 坐骑结构装备 | 铜/铁/金/钻石/下界合金马铠；全部鹦鹉螺铠 | 除皮革马铠外依赖有限结构战利品或其升级；从已装备生物取回只是返还，不是净生成 |
| 考古物 | 陶片及考古独占战利品 | 可疑沙/沙砾不会重新生成战利品 |
| 有限植物 | 枯萎的灌木、孢子花 | 无正常生长、骨粉复制或稳定交易来源 |
| 26.2 地形材料 | 朱砂及其建筑系列 | 硫黄可通过尖锥再生，但朱砂没有对应生产机 |
| 天然基底石材 | 下界岩、深板岩、凝灰岩、方解石及其有限底材系列 | 可继续探索开采，但没有正常无限净生成机制 |
| 不可取得方块 | 紫水晶母岩、普通/试炼刷怪笼、宝库、末地传送门框架、强化深板岩、基岩 | 生存中没有正常物品形态掉落 |

例外说明：钻石装备可以通过村民交易重复购买，极低概率穿戴钻石装备的怪物也可能掉装备；这不代表钻石本身可无限生产。

## 漏洞与非常规边界单独归档

| 机制 | 能处理或复制什么 | 26.2 使用风险 |
| --- | --- | --- |
| TNT 实体复制 | 为爆破室、树场、隧道机和世界吞噬者提供无限点燃 TNT | 原版可能仍可用，但不是预期机制，服务端常修复 |
| 重力方块复制 | 沙、红沙、沙砾、混凝土粉末等 | 常利用末地传送门；会改变这些资源的正常可再生性结论 |
| 铁轨/地毯等物品复制 | 对应物品 | 兼容性记录零散，版本和服务端差异大 |
| 虚空交易 | 绕过村民库存或补货 | 非预期行为，不应作为默认交易产能依据 |
| 存档/容器回滚 | 理论上可复制任意物品 | 有坏档和服务器处罚风险，不属于生电生产线 |
| 宝库 UUID 记录边界 | 让至少 129 名真实玩家轮换宝库记录 | 属于固定容量记录的多人边界，不是物品复制漏洞；不应据此把钻石或宝库限领物标为普通单人可再生 |

潜影贝被潜影弹命中后复制、盘丝效果生成蜘蛛网、泥巴转黏土和试炼刷怪笼冷却都是正式机制，不属于复制漏洞。

## 规划一座生电基地的推荐顺序

1. 先完成村民繁殖、铁场、基础作物田和简易经验源。
2. 建立甘蔗、竹子、南瓜/西瓜、蜂蜜、羊毛与苔藓骨粉等低风险全自动农场。
3. 建金塔并接猪灵以物易物，解锁石英、黑石、沙砾、灵魂沙和哭泣的黑曜石工业。
4. 补齐苦力怕、史莱姆、守卫者、烈焰人、凋灵骷髅和末影人等专用塔。
5. 用合成器、超级熔炉、单物品分类、潜影盒装卸和溢出停机把分散的农场连成生产系统。
6. 最后再建设袭击塔、潜影贝农场、凋灵笼、世界吞噬者等高风险或版本敏感工程。

选择具体教程时至少核对：**Java/Bedrock、精确游戏版本、单机/服务器、是否依赖 TNT 复制、是否要求特定难度和游戏规则、是否允许区块加载器**。
